# Syntecxhub - Customer Segmentation using RFM Analysis

## Overview
This project performs customer segmentation using the RFM (Recency, Frequency, Monetary) framework to classify customers into actionable groups for targeted marketing.

## Segments Identified:
- **Champions / Loyal:** Highly engaged customers who purchase frequently and recently.
- **New / Potential:** Recent buyers with room to increase purchase frequency.
- **At Risk:** High lifetime value but haven't purchased recently. Re-engagement needed.
- **Lost Customers:** Inactive accounts with low recency and engagement.

## Outputs
- `rfm_segmented_customers.csv`: Full dataset with calculated RFM scores and assigned segments.
- `rfm_distribution_chart.png`: Visual distribution of customer segments.

## Tech Stack
- Python, Pandas, Matplotlib, Seaborn
