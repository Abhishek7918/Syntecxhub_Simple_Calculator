# Simple Calculator - Syntecxhub Internship

A clean, modular command-line interface (CLI) calculator built with Python for Week 1 task at Syntecxhub.

## Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division
- Input validation to avoid runtime errors
- Zero-division error handling
- Interactive loop with exit option

## How to Run
1. Make sure Python 3 is installed.
2. Run the script:
   ```bash
   python calculator.py
